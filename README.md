# helloworldsimplejavaprogram

A progressive Java learning project for building programming foundations
while learning professional GitHub, VS Code, and Git workflows.

## Java Foundation

The project was developed progressively through 10 learning stages:

- V1 — Basic Java
- V2 — if / else
- V3 — for loop
- V4 — while loop
- V5 — Methods
- V6 — Return values
- V7 — Arrays
- V8 — ArrayList
- V9 — Classes & Objects
- V10 — Integrated Java Program

## Technologies & Tools

- Java
- VS Code
- Git
- GitHub
- GitHub Copilot

## Development Workflow

Code → Test → Branch → Commit → Push → Pull Request
→ Review → Merge → Sync → Cleanup
